# 虚拟定位助手 (MockLocation Assistant)

一款轻量、无广告、免 Root 的 Android 虚拟定位应用。支持在地图上直接选点、搜索地点/经纬度、高德/百度/WGS-84 坐标系自动精准纠偏、方向微调与模拟行走，修改手机系统级定位后，高德地图、百度地图、腾讯地图、Google 地图等均可实时显示指定位置。

---

## 功能亮点

- **免 API Key 双底图选点**：内置高德街道、高德卫星图与 OpenStreetMap 全球底图，无需申请地图开放平台 Key，国内网络直连秒开。
- **三大坐标系自动精准纠偏**：内部自动处理 `WGS-84`（系统 GPS）、`GCJ-02`（高德/腾讯）与 `BD-09`（百度）的相互转换，避免定位偏移数百米。
- **智能搜索与坐标识别**：支持地名搜索、内置 25 个常用国内外城市快速跳转，以及直接粘贴 `"纬度, 经度"` 或 `"经度, 纬度"`（自动识别高德/百度坐标拾取器顺序）。
- **高德/vivo 防跳回 10Hz 引擎**：支持 100ms (10Hz) 高频位置注入、`gps`/`network`/`fused` 全通道覆盖、唤醒锁与后台 `LocationListener` 保活、可拖拽悬浮窗保活胶囊，并提供一键「防跳回设置」诊断面板。
- **微调与模拟行走**：支持 10m / 50m / 200m 东南西北微调与连续模拟行走模式，并支持收藏常用地点与历史记录。

## 如何上传到 GitHub 并自动生成手机安装包 (.apk)

本仓库已内置 GitHub Actions 自动化编译工作流（[build-apk.yml](.github/workflows/build-apk.yml)），你无需在电脑上安装 Android Studio 或配置任何 SDK，GitHub 会自动帮你打包并发布可直接下载安装的 APK。

### 第一步：上传代码到你的 GitHub 仓库

1. 在 GitHub 上新建一个仓库（例如 `mock-location-app`）。
2. 在本机项目目录中执行以下命令关联并推送（将 `<你的用户名>` 和 `<仓库名>` 替换为你的实际信息）：

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

### 第二步：在手机上直接下载并安装 APK

1. 推送成功后，打开你的 GitHub 仓库页面，点击顶部的 **Actions**，等待 `Build & Release Android APK` 任务运行完成（约 2～3 分钟变成绿色对勾 ✅）。
2. 完成后，回到仓库首页右侧的 **Releases**（或直接用手机浏览器打开 `https://github.com/<你的用户名>/<仓库名>/releases`）。
3. 点击下载 **`MockLocation-latest.apk`**，即可直接在安卓手机上点击安装。

## 手机端使用教程

1. **开启手机开发者模式**：
   打开手机 **系统设置 → 关于手机**，连续点击 **“版本号”**（部分机型为 MIUI 版本 / ColorOS 版本 / HarmonyOS 版本）7 次，直到提示“您已处于开发者模式”。
2. **授权模拟位置应用**：
   打开 **系统设置 → 开发者选项**（部分机型在“更多设置/系统和更新”内），找到 **“选择模拟位置信息应用”**，点击选择 **虚拟定位助手**。
3. **开始虚拟定位**：
   - 打开 **虚拟定位助手**，授予“位置信息”和“通知”权限；
   - 在地图上点击想去的位置（或通过搜索框、热门城市、输入坐标定位）；
   - 点击底部 **「开始虚拟定位」**，通知栏出现常驻提示后即可；
   - 打开高德地图、百度地图、腾讯地图等软件，点击定位按钮即可看到当前位置已切换为指定地点。

### vivo (OriginOS) 及国产手机防 1~2 秒跳回真实位置指南
如果在高德地图中刚打开时显示虚拟位置，1~2 秒后又跳回真实位置，通常是因为 Wi-Fi/WLAN 扫描反查或 OriginOS 后台冻结，请在 App 顶部点击 **「防跳回设置」** 依次完成：
1. **关闭 Wi-Fi 开关**（改用移动数据，防止高德 SDK 通过周围路由器 MAC 反查真实位置）。
2. **关闭系统的「WLAN 扫描」与「蓝牙扫描」**（设置 → 隐私 → 定位服务 → 扫描设置）。
3. **忽略电池优化 & 允许后台高耗电**：在应用详情 → 电量中设为“允许后台高耗电”，并在多任务后台将 **虚拟定位助手** 下拉加锁。
4. **开启悬浮窗保活胶囊**：切入高德后屏幕上保留小型定位状态胶囊，防止系统在切后台后 2 秒内限制后台线程。

### 关于微信的说明
- 本应用基于 Android 官方「开发者选项 → 模拟位置信息应用」标准接口实现，未 Root 设备下系统底层会为模拟位置打上 `isFromMockProvider` 标记。
- 微信内置了 `isFromMockProvider()` 检测及手机基站交叉校验，因此通过系统开发者选项无法改变微信「共享实时位置」「附近的人」等功能的定位（高德、百度、腾讯地图、Google 地图等遵循标准定位接口的应用均可正常生效）。
